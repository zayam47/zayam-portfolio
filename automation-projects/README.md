# Automation Projects

n8n workflows designed and built by Zayam Mushtaq as portfolio demonstrations
of AI-agent and business-process automation. Each folder has the importable
`workflow.json` plus a README explaining the design.

- [`ai-lead-qualification-crm-sync/`](ai-lead-qualification-crm-sync) — AI
  scores and routes inbound leads into Kommo / GoHighLevel automatically.
- [`content-repurposing-publisher/`](content-repurposing-publisher) — AI
  repurposes published content into LinkedIn/Twitter/Instagram drafts with a
  Slack approval step.

Both are built for self-hosted or cloud n8n (community edition compatible).
Import a workflow via **Workflows → Import from File**, then attach your own
credentials for the services it calls — see each project's README for the
exact list.
